{% comment %} * [RESUMO] → UM produto na tela "Estoque no Full": um BLOCO. FECHADO, ele é uma linha só e clara (seta, foto, título e os números do produto = a soma dos Códigos ML dele), para dar para rolar a lista e comparar um produto com o outro. ABERTO (a seta), a linha ganha um fundo azulado e, embaixo dela, aparecem os motivos do indisponível, o link do Planejamento e um cartão por Código ML (as contas que fecham o total), com os anúncios de cada Código dentro do cartão (script_full_estoque.js). Os números do produto vêm SÓ de Códigos ML que já foram consultados; se algum não foi, o total aparece marcado como "parcial". As colunas da linha têm as mesmas larguras da barra de colunas (que fica fixa no alto ao rolar) e do cartão de cada Código: por isso os números ficam alinhados. Em tela larga os nomes das colunas só aparecem nessa barra; em tela estreita (a lista rola para o lado e a barra não acompanha) cada número volta a mostrar o próprio nome. Recebe: produto (um item de pagina.produtos), aberto (True = Códigos ML já vêm abertos), badge_a_caminho. {% endcomment %}
