Como ler a tabela
  • Da esquerda para a direita: 1 Produto (quem é) → 2 O que cada fonte diz (os números crus de cada fonte, sem conta) → 3 Contas (a diferença entre duas colunas do bloco 2; o cabeçalho de cada conta mostra de quais colunas ela vem) → 4 Achados (o que está estranho naquele SKU).
  • Cores das fontes: Arquivo do ERP API Sysemp API Mercado Livre — as mesmas cores nos cartões de cima, nas colunas e nas contas.
  • Δ é a conta "coluna da esquerda − coluna da direita". 0 igual; +3 ou −2 diferente; — não dá para calcular (falta número em uma das fontes).
  • — quer dizer "sem dado nessa fonte". Nunca é zero: o SKU não está lá, ainda não foi consultado ou a fonte não tem esse número.
  • 0 em cinza é um zero implícito: a API Sysemp só manda linhas com estoque maior que zero. Com a coleta completa, SKU que não veio vale 0. Com a coleta incompleta, ele aparece como — (não sei).
  • Full: o estoque que o ERP controla do Full (API Sysemp) × o Full do Mercado Livre. Flex: o estoque fora do Full, nas 3 fontes. O que cada local significa está em comparativo_estoque_locais.py.
  • Ordenar: clique no título de uma coluna; clique de novo para inverter. Vale para todos os SKUs, não só os da página. O "—" fica sempre no fim. Nas colunas Δ, a ordem é pela maior diferença, ignorando o sinal.
  • Rolagem: a tabela rola sozinha, para baixo e para o lado. O cabeçalho e as colunas do produto (foto, SKU, título e marca) ficam fixos enquanto você rola.
  • Abra uma linha (seta à esquerda) para ver o que não cabe na tabela: outras colunas do arquivo, locais da Sysemp fora da tabela, os Códigos ML e os achados do SKU.
