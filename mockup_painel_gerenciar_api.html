Reautorizar o Google Drive

  1. Abra Status do app (menu "Abrir no Google"). Se estiver em Testando, clique em Publicar app. Em Testando, a autorização expira a cada 7 dias.
  2. No computador de desenvolvimento, rode o comando abaixo e entre com a conta dona do Drive:
    poetry run python autorizar_drive_oauth.py
  3. Volte a esta tela e clique em Testar agora. O estado deve passar para "Funcionando".
O comando não contém senha nem token. O token novo é gravado direto no arquivo do servidor e nunca passa por esta tela.
